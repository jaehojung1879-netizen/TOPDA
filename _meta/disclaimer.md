# 면책 문구 (원본)

> 이 파일의 문구는 모든 글·체크리스트 하단에 동일하게 삽입한다. 임의 수정 금지.

---

## 일반 글용 (기본)

```
본 콘텐츠는 일반적인 정보 제공을 목적으로 하며, 개별 사안에 대한 법률·
세무·금융 자문이 아닙니다. 구체적인 의사결정은 변호사·세무사·공인중개사·
자격 있는 금융기관과 상의하시기 바랍니다. 게재 시점 기준이며 이후 법령·
정책 변경으로 달라질 수 있습니다.

작성일: YYYY.MM.DD
최종 갱신일: YYYY.MM.DD
```

## 세무·법률 비중이 큰 글용 (강화)

```
본 콘텐츠는 세법·민법·임대차 관련 법령에 대한 일반적 안내이며, 개별
사안에 대한 세무·법률 자문이 아닙니다. 세율·요건·절차는 개별 상황과
시점에 따라 다를 수 있으며, 시행령·예규·고시 등 하위 규정에 의해
달라질 수 있습니다. 구체적 사안은 반드시 세무사·변호사 등 자격 있는
전문가의 상담을 받으시기 바랍니다.

작성일: YYYY.MM.DD
최종 갱신일: YYYY.MM.DD
```

## 대출·금융상품 글용 (강화)

```
본 콘텐츠는 주택 관련 금융상품에 대한 일반 정보이며, 특정 상품의
권유·중개·소개가 아닙니다. 금리·한도·자격요건은 시점·금융기관·
개인 신용에 따라 다르며, 정책상품은 정부 정책 변경에 따라 수시로
바뀝니다. 실제 신청·계약 시에는 해당 금융기관 또는 정부 포털의
최신 정보를 확인하시기 바랍니다.

작성일: YYYY.MM.DD
최종 갱신일: YYYY.MM.DD
```

## 광고·제휴 링크 포함 글 (추가 표시)

본문 상단 + 제휴 링크 직전에 다음을 추가:

```
본 페이지는 제휴 링크를 포함하며, 클릭·구매 시 일정 수수료가 사이트
운영비로 사용됩니다. 수수료 여부와 무관하게 정보 내용은 영향을 받지
않습니다.
```
