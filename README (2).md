# Assets

이미지·로고·아이콘·폰트 등 시각 자료 저장소.

---

## 폴더 권장 구조

```
assets/
├── logo/                 # 로고 SVG·PNG (외주 받은 원본 포함)
├── images/               # 글 본문용 이미지
│   ├── posts/
│   └── checklists/
├── icons/                # 카테고리·태그 아이콘
└── covers/               # 글·체크리스트 커버 이미지
```

---

## 라이선스 원칙

다음 출처만 허용:
- 본인 제작·촬영
- Unsplash, Pexels (라이선스 확인 후)
- 공공누리 1~4유형 (조건 확인)
- 정부 공공저작물

다음은 금지:
- 출처 불명 이미지
- 상업용 스톡 사이트 라이선스 미확인 이미지
- 타 블로그·SNS 이미지 무단 사용

---

## 파일명 규칙

- 영문 소문자 + 하이픈
- 예: `balance-day-cover.jpg`, `category-icon-sale.svg`

---

## 최적화

- 본문 이미지: 1200px 폭 이내, WebP 또는 JPG 80% 품질
- 커버 이미지: 1600x900px, WebP
- 로고: SVG 우선
