운영·편집 원칙

톺다가 무엇을 위해 존재하고, 정보를 어떤 절차로 만들고 고치는지 밝힌 문서입니다.

1. 사이트 운영 목적

톺다는 주택을 사거나 임차할 때 필요한 숫자를 직접 계산해 보게 하는 도구 사이트입니다. 다음 다섯 단계를 한 사이트 안에서 끝내는 것을 목표로 합니다.

  1. 주택 매수에 드는 총비용 계산 — 취득세·중개보수·등기비용·채권매입·잔금일 정산
  2. 대출 가능액과 월 상환 부담 확인 — LTV·DSR·스트레스 DSR, 상환 방식 비교
  3. 계약·전세·세금 위험 확인 — 등기부등본, 대항력·우선변제권, 세금 중과 조건
  4. 단계별 체크리스트 제공 — 계약·잔금일·이사 당일에 실제로 해야 하는 일
  5. 계산 결과의 저장·공유 및 관련 가이드 연결

트래픽을 늘리기 위해 페이지 수를 불리는 것은 목적이 아닙니다. 검색 유입이 되더라도 위 다섯 단계에 기여하지 않는 페이지는 검색 색인에서 제외합니다.

2. 공식 출처 우선 원칙

모든 수치·요건은 1차 출처에서 확인합니다. 우선순위는 다음과 같습니다.

  1. 법령 조문 — 국가법령정보센터의 법률·시행령·시행규칙 원문
  2. 지방자치단체 조례·고시 — 중개보수 상한요율 등 지자체가 정하는 항목
  3. 소관 부처·공공기관 발표 자료 — 국토교통부, 기획재정부, 행정안전부, 국세청, 금융위원회
  4. 공공데이터 OpenAPI 원자료 — 실거래가, 공동주택 기본정보, 건축물대장, R-ONE 통계

블로그·요약 기사·다른 계산기 사이트를 근거로 삼지 않습니다. 언론 보도는 “언제 무엇이 바뀌었는지”를 찾는 단서로만 쓰고, 실제 내용은 반드시 공식 원문으로 확인한 뒤 적습니다.

3. 정보 작성과 검토 절차

작성1차 출처를 읽고, 적용 조문·기준일·가정을 페이지에 명시한 상태로 씁니다. 근거를 찾지 못한 항목은 넣지 않습니다.
계산 검증계산기는 조문의 구간·상한을 놓고 경계값(0원, 구간 경계 금액, 상한 초과, 소수점)을 손으로 계산해 대조합니다. 세율·요율 변경 시 자동 테스트로 이전 결과와 차이를 확인합니다.
표시직접 작성한 글에는 작성자, 최초 게시일, 최근 검토일, 사용한 공식 출처, 적용 기준일을 화면에 표시합니다.
재검토세율·요율·규제가 바뀌었다는 단서가 있으면 해당 계산기와 관련 글을 함께 다시 봅니다. 정기 일정이 아니라 변경 사실을 기준으로 움직입니다.
정정오류가 확인되면 고치고, 무엇을 언제 어떻게 고쳤는지 정정 안내에 남깁니다.

4. 하지 않는 것

  • 추정·보간·예측을 하지 않습니다. 데이터가 없는 기간은 비워 두고, 없는 값을 채우지 않습니다. 표본이 적으면 표본 수와 주의사항을 함께 표시합니다.
  • 보유하지 않은 자격·감수를 표기하지 않습니다. 톺다에는 외부 전문가 감수 절차가 없고, 운영자는 부동산 관련 자격을 보유하고 있지 않습니다. 그러므로 감수자·검수 전문가를 표시하지 않습니다.
  • 투자 권유를 하지 않습니다. 특정 지역·단지·상품을 사라거나 팔라고 하지 않고, “오를 것”·“유망하다” 같은 전망을 쓰지 않습니다.
  • 기사 본문을 옮기지 않습니다. 외부 보도를 인용할 때는 무엇이 바뀌었는지 직접 요약하고 공식 원문 링크를 제시합니다. 기사 문장을 복사하거나 제목 목록을 자동으로 늘어놓지 않습니다.
  • 분량을 늘리기 위한 문장을 쓰지 않습니다. 검색 키워드를 반복하거나 일반론을 덧붙여 글자 수를 채우지 않습니다.

5. 자동 수집 데이터와 직접 작성 콘텐츠의 구분

구분해당 페이지표시 방식
직접 작성 가이드(/posts/), 체크리스트, 계산기, 안내·정책 페이지 작성자·최초 게시일·최근 검토일·사용 출처·적용 기준일을 본문에 표시
공공데이터 가공 지역·단지 실거래 페이지(/apt/), 시세 대시보드, 전세가율·상업용 임대 지도 출처 기관·집계 구간·데이터 기준일을 표시. 사람이 쓴 해설 문장이 없으므로 작성자를 붙이지 않음

공공데이터 가공 페이지는 값이 매일 바뀌므로 “문서”가 아니라 “조회 결과”에 가깝습니다. 그래서 이 페이지들은 사용자가 언제든 열어 볼 수 있게 유지하면서도, 데이터가 충분히 쌓여 페이지 고유의 분석이 성립할 때만 검색 색인을 허용합니다. 기준은 데이터 기준에 공개했습니다.

6. 데이터 갱신 주기

실거래가매일 수집. 국토교통부 신고 자료 기준이며 신고 지연·정정·해제로 값이 바뀝니다. 해제(취소) 거래는 모든 집계에서 제외하고 표에만 별도 표시합니다.
공동주택 기본정보(세대수·준공연도)K-apt 및 건축물대장 기준. 원자료 갱신 시 반영합니다.
가격지수·전세가율한국부동산원 R-ONE 월간 통계 기준. 통계 발표 주기에 맞춰 갱신합니다.
세율·요율·규제정해진 주기가 없습니다. 법령·고시 개정 시점을 기준으로 갱신하고, 각 계산기에 적용 기준일을 표시합니다.

각 페이지 하단의 “데이터 기준일”이 그 페이지에 실제로 반영된 시점입니다. 갱신 주기와 다를 수 있으므로 페이지에 적힌 기준일을 신뢰하시면 됩니다.

7. 계산기 버전 관리 방식

  • 계산 로직을 바꾸면 해당 계산기 페이지의 변경 이력 항목에 날짜와 바뀐 내용을 적습니다.
  • 세율·요율 표는 코드에서 상수로 분리해 두고, 적용 기준일을 함께 기록합니다. 화면의 “적용 기준일”은 이 값에서 나옵니다.
  • 세제·상환 계산에는 자동 테스트가 있어, 로직 변경이 기존 결과를 의도치 않게 바꾸면 배포 전에 실패합니다.
  • 결과가 달라지는 변경(세율 개정 등)은 이력에 남기고, 표기·문구만 다듬은 변경은 남기지 않습니다.

8. 법률·세무·금융 자문이 아닙니다

⚠
톺다의 모든 글·계산기·데이터는 일반 정보 제공용입니다. 개별 사안에 대한 법률·세무·금융 자문이 아니며, 자문을 대신할 수 없습니다. 법령·세율·정책은 바뀌며, 게재 내용과 실제 법령이 다를 경우 법령이 우선합니다. 실제 계약·납세·대출 결정은 변호사·세무사·공인중개사·자격 있는 금융기관과 상의하십시오. 계산기는 입력 조건에 따른 추정값을 보여주며, 실제 고지·부과 금액과 다를 수 있습니다.

9. 오류 제보와 정정

잘못된 숫자나 오해를 부르는 설명을 발견하면 알려주세요. 접수·확인·정정 절차와 지금까지 고친 내역은 정정 안내에 있습니다. 접수 창구는 문의 안내를 참고하세요.

10. 광고와 편집의 분리

  • 톺다는 Google AdSense 광고로 운영비를 충당합니다. 광고 게재 사실과 쿠키 사용은 개인정보 처리방침에 밝혀 두었습니다.
  • 광고주가 글의 내용·계산 로직·평가에 관여하지 않습니다. 특정 업체·상품을 유리하게 쓰는 대가를 받지 않습니다.
  • 광고는 완성된 콘텐츠와 계산기 페이지에만 넣습니다. 정책·문의·정정 안내, 게시판, 내부 검색 결과, 검색 색인에서 제외한 페이지, 오류 페이지에는 넣지 않습니다.
  • 광고 단위를 본문보다 먼저 보이게 배치하거나, 탐색을 방해하는 위치에 넣지 않습니다.
  • 대가를 받은 링크가 생기면 해당 위치에 광고·제휴 표시를 부착합니다. 현재 제휴 링크는 없습니다.
