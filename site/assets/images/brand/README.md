# 톺다 브랜드 로고

새 TOPDA 로고 파일을 이 폴더에 올려주세요.

## 업로드 방법

1. GitHub에서 이 폴더(`site/assets/images/brand/`)를 연다
2. **Add file → Upload files**로 이미지를 올린다
3. 파일명은 아래 규칙을 따른다

## 파일명 규칙

| 파일명 | 용도 | 권장 크기 |
|---|---|---|
| `logo.png` | 사이트 헤더·파비콘·앱 아이콘 원본 | 1024×1024 (정사각) |
| `logo-og.png` | (선택) SNS 공유 카드용 | 1200×630 |

- PNG 권장(투명 배경이면 더 좋음). JPG도 가능.
- 파일명은 소문자 고정 — 코드가 이 이름을 참조한다.

## 업로드 후

`logo.png`가 올라오면 다음 작업으로 반영됩니다 (Claude에게 "로고 반영해줘"라고 요청):
- 사이트 헤더 브랜드 마크 (`assets/brand-mark.svg` 대체)
- 파비콘 (`<link rel="icon">`)
- OG 이미지 (`og-default.svg` 대체 — SNS·검색 썸네일)
- 정적 지역 페이지(`/apt/`) 헤더

업로드만으로 자동 반영되지는 않습니다(깨진 참조 방지를 위해 파일 확인 후 코드 반영).
