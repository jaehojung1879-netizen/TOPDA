임장 체크리스트 30선

최근 갱신·8분 읽기
한 줄 결론

같은 단지에서 동·층·향이 다른 최소 3호를 비교 임장. 낮 12시~오후 2시가 채광 판단 황금 시간. 비 오는 날은 누수·결로 발견에 유리합니다.

목차

  1. 건물 외부 (단지 진입~동 앞까지)
  2. 해당 호수 (현관 들어서면서)
  3. 하자·노후 (분쟁 예방)
  4. 주변 환경 (외부에서 보기)
  5. 임장 가기 전 사전 준비
  6. 관련 자료

건물 외부 (단지 진입~동 앞까지)

  1. 역까지 실측 도보 시간 — 광고와 다를 수 있음. 휴대폰 만보기로 측정
  2. 단지 진입로 너비·교통량 — 출퇴근 시간 정체 여부
  3. 가로등·CCTV — 야간 보안
  4. 주차장 진입 동선 — 지상/지하, 출입구 위치
  5. 관리사무소·경비실 — 청결도가 단지 관리 상태의 1차 지표
  6. 놀이터·헬스장·커뮤니티 시설 — 노후도·청결도
  7. 인근 학교·학원 거리 — 지도로 미리 + 도보로 확인
  8. 인근 상권 — 마트·약국·세탁소·은행

해당 호수 (현관 들어서면서)

  1. 현관문 방음·디자인·번호키 — 교체 시 50~100만원
  2. 현관 신발장 수납 — 4인 가족 기준 충분한지
  3. 거실 채광·향 — 정오 기준 햇빛이 어디까지 들어오는지
  4. 발코니 확장 여부 — 실평수 차이가 큼. 외기 단열 여부도 확인
  5. 맞통풍 가능성 — 현관→거실→안방으로 바람이 통하는지
  6. 천장 높이 — 표준 2.3m, 신축은 2.5m 이상
  7. 방 개수·크기 — 평면도와 실제 비교
  8. 붙박이장·옷장 — 옵션 잔류 여부와 상태
  9. 주방 동선·수납 — 싱크대·렌지·냉장고 위치 동선
  10. 욕실 환기·누수 흔적 — 천장·벽 모서리 곰팡이 확인

하자·노후 (분쟁 예방)

  1. 창틀 결로·곰팡이 — 단열·이중창 부재 신호
  2. 도배·바닥재 들뜸 — 전 시공 부실 가능성
  3. 벽 균열 — 구조적 문제 vs 단순 미관 균열 구분
  4. 천장 누수 자국 — 윗집·옥상 누수 가능성
  5. 수압 — 욕실·주방 모두 동시에 틀어 확인
  6. 온수 나오는 속도·온도 — 보일러 노후도
  7. 전기 콘센트·LED 등 — 노후 시 교체 비용
  8. 창문 개폐 부드러움 — 샷시 노후 신호
  9. 화장실 변기·세면대 노후 — 교체 시 30~100만원
  10. 주방 가구·상판 흠집 — 인테리어 교체 비용 가늠

주변 환경 (외부에서 보기)

  1. 해당 동 일조량 — 앞동 거리, 가림 여부
  2. 층간소음 — 윗집·아랫집 발소리 들리는지 (가능하면 윗집 방문 양해 구해)
  3. 외부 소음 — 도로·철도·학교·상가 영향
  4. 주차 자리 — 야간 시간대 가서 자리 확보 가능한지
  5. 엘리베이터 대기 시간 — 출근시간대 체험
  6. 관리비 수준 — 단지 평균 + 해당 호수 최근 3개월 확인

임장 가기 전 사전 준비

  • 등기부등본 발급 (계약 직전·잔금 직전 재발급)
  • 건축물대장 발급 (위반건축물 여부)
  • 실거래가 조회 (rt.molit.go.kr 최근 3개월)
  • 휴대폰 만보기·줄자·전등 앱 준비
  • 시간대: 낮 12시~오후 2시 1차 + 저녁 7시 2차
