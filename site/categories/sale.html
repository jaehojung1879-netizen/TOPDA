매매 종합 가이드

전체 흐름 · 공식 계약서 · 필수 확인 사항 · 최종 갱신 2026.05.25
한 줄 결론

‘예산 → 매물 → 계약 → 잔금 → 등기’ 5단계만 정확히 밟으면, 보통의 매매는 4~8주 안에 마무리됩니다.

전체 흐름 (5단계)

평균 6~8주. 자금 준비가 되어 있다면 4주도 가능합니다.

예산 수립 · 자금 계획

D-60 ~ D-30

자기자본 + 가능한 대출액 + 부대비용(취득세·중개수수료·법무사·이사·인테리어)을 합산해 ‘총 사용 가능 금액’을 산정합니다.

DSR·LTV 한도 확인 (은행 또는 정부24 ‘주택담보대출 한도 사전 확인’) 부대비용 추정: 취득세 계산기 · 중개수수료 계산기 최소 1~3주 비상금 분리 보관

매물 탐색 · 임장

D-30 ~ D-7

실거래가·시세를 비교한 뒤 임장에서 실사용 가치를 확인합니다. 같은 단지·평형이라도 동·층·향에 따라 1억 차이 나는 게 흔합니다.

실거래가: 국토교통부 ‘실거래가 공개시스템’ (rt.molit.go.kr) 등기부등본 발급(인터넷등기소) → 소유자·근저당·가압류·임차권 확인 건축물대장 확인(정부24) → 위반건축물 여부 임장 시 채광·환기·층간소음·주차·관리상태 직접 확인

계약 (계약금 5~10%)

D-day (계약일)

계약금은 보통 매매가의 5~10%. 계약 즉시 임의 해지가 어려워지므로 가계약 전 자금·대출 가능 여부를 최종 확인해야 합니다.

등기부등본을 ‘계약 당일 아침’에 재발급하여 가압류·근저당 변동 확인 매도자 본인 여부·신분증 대조 중도금·잔금 일정과 금액 명시 특약사항(현 상태·하자보수·옵션 인계·잔금일 정산) 명문화 계약 후 30일 내 부동산거래신고 (보통 중개인이 처리)

중도금 (생략 가능)

D-day + 2~6주

매매가의 30~40%를 중도금으로 납부. 중도금 송금 후에는 매도자의 단순 해약이 거의 불가능합니다(이행착수). 계약금만으로 잔금까지 가는 경우도 많습니다.

중도금이 있다면, 이체일·계좌 명문화 중도금 송금 시 등기부등본 재확인

잔금 · 등기 이전

잔금일

잔금 송금과 동시에 등기 이전을 신청합니다. 법무사 동행이 일반적. 잔금일 정산(관리비·선수관리비·장기수선충당금)을 한 번에 처리합니다.

잔금일 아침 등기부등본 ‘마지막’ 재발급 잔금 송금 → 매도자 통장 입금 확인 → 법무사가 등기 신청 취득세 신고·납부 (잔금일 ~ 60일 내, 실무상 당일) 관리비 일할·선수관리비·장기수선충당금 정산 전입신고 (잔금일 ~ 14일 내)

공식 계약서

표준계약서를 사용하면 누락·불공정 조항 위험을 크게 줄일 수 있습니다. 중개사가 다른 양식을 권하더라도 표준양식을 기준으로 검토하세요.

국토교통부 표준

부동산 매매계약서 (주택)

발행: 국토교통부 · 공인중개사협회 공통 사용

  • 매매대금·계약금·중도금·잔금 일정과 금액
  • 등기 이전에 필요한 서류와 시점
  • 위약금(통상 계약금 상당) 조항
  • 특약사항란 — 가장 중요. 옵션·하자·정산 모두 여기 명기

핵심 비용

대략적인 부대비용 비율(매매가 10억 기준).

항목비율 / 기준10억 매매 시 예시
취득세1.0% ~ 12% (주택 수·지역)1주택 약 3,300만원
농어촌특별세85㎡ 초과 시 0.2%약 200만원
지방교육세취득세의 10% 수준약 330만원
중개수수료0.4~0.7% + 부가세약 440만원
법무사비30~80만원약 50만원
인지세·증지·국민주택채권몇만~수십만원약 30만원
합계(1주택 가정)약 4,350만원

정확한 금액은 취득세 계산기 및 중개수수료 계산기를 활용하세요.

놓치면 위험한 7가지

⚠
등기부등본은 ‘계약 직전·중도금·잔금일 아침’ 3회 발급 가압류·근저당은 하루 사이에도 추가될 수 있습니다. 인터넷등기소에서 1,000원으로 발급 가능합니다.
  1. 이체 한도 — 1일 이체 한도를 미리 상향해 두지 않으면 잔금 송금이 막힙니다.
  2. 건축물대장 확인 — ‘위반건축물’ 표시가 있으면 대출이 막힐 수 있습니다.
  3. 임차인 있는 매물 — 대항력 임차인은 매수자에게 승계됩니다. 보증금 인수 여부 명문화.
  4. 관리비 미납 — 잔금일 정산 시 매도자의 미납 관리비 확인.
  5. 선수관리비 정산 — 매수자가 매도자에게 별도 반환해야 하는 금액.
  6. 대출 실행 일정 — 잔금일에 대출 실행이 안 되면 계약 위반 위험.
  7. 등기 완료 확인 — 잔금 후 1~2주, 등기부등본에 자기 이름이 올라왔는지 반드시 확인.
