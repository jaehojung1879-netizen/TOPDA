전세가율 지도

국토교통부 아파트 매매·전세 실거래 중위가 기준 · 매일 자동 갱신
⚠
예시 데이터입니다. 전세(전월세) 실거래 API 승인 후 실제 값으로 자동 갱신됩니다. 아래 숫자는 화면 예시이며 실제 시세가 아닙니다.
≈
전세 중위가는 추정치입니다. 매매 실거래 중위가(실측)에 한국부동산원 R-ONE 지역 전세가율을 곱해 산출했습니다. 전월세 실거래 API 승인 후 실거래 기준으로 자동 전환됩니다.
i
전세가율 = 전세 중위 보증금 ÷ 매매 중위가 지역별 최근 3개월 실거래(순수 전세)로 계산합니다. 전세가율이 높을수록 매매가 대비 전세 부담이 크고 역전세·갭 위험을 살펴야 합니다.

실거래 데이터를 준비 중입니다. 매일 자동 수집 후 표시됩니다.

읽는 법 · 출처
  • 중위가를 쓰는 이유 — 평균은 초고가·초저가 거래에 휘둘리므로, 지역 대표값으로 중앙값을 사용합니다.
  • 순수 전세(월세 0)만 집계해 보증금 기준 전세가율을 계산합니다. 표본이 적은 지역(각 5건 미만)은 제외됩니다.
  • 지역 구성(평형·연식)이 매매·전세에서 다를 수 있어 참고용 근사치입니다. 단지·평형 단위는 실거래가 조회에서 확인하세요.
