# 방문자 관점 문구 점검 — 2026-08-17

## 판단 기준

- 첫 화면과 도구 화면은 방문자가 지금 할 수 있는 행동과 결과를 먼저 말한다.
- 개발 과정, 내부 우선순위, 데이터 파이프라인 설명은 공개 화면에 두지 않는다.
- 법적 기준일·계산 가정·결과가 달라지는 조건처럼 판단에 필요한 내용은 남긴다.
- 자동 점수나 추세는 미래를 보장하는 ‘추천’처럼 표현하지 않는다.

## 이번에 바로 고친 부분

- 15개 계산기에서 개발용 ‘계산 방식 변경 이력’, 내부 이슈 설명과 예시값을 제거했다.
- 계산기 모음의 ‘공식 자료 기반 인터랙티브 도구’를 사용자가 할 수 있는 행동 중심 문장으로 바꿨다.
- ‘부동산 종합 계산 대시보드’를 ‘부동산 종합 계산기’로 통일했다.
- 맞춤 내집 찾기의 ‘상승기대’, ‘추천 받기’를 ‘최근 가격 흐름’, ‘단지 찾기’로 바꿨다.
- 상가 임차시세 화면의 환경변수명과 데이터 연동 방법을 빼고, 최신 시세 확인 안내만 남겼다.
- 게시판 운영자 안내에서 Supabase Vault 등 구현 용어를 제거했다.

## 남겨 둔 설명

- 계산기의 적용 기준일, 출처, 계산 가정과 오차 가능성은 결과 해석에 필요하므로 유지한다.
- 데이터가 준비되지 않았거나 표본이 부족하다는 경고는 숨기면 오히려 오해를 만들 수 있어 유지한다.
- 개인정보·저장 방식·서비스 한계는 첫 화면이 아니라 안내·약관·개인정보 페이지에서 설명한다.

## 다음 점검 후보

- ‘지역 시세·전세가율 대시보드’, ‘대출 한도 시뮬레이터’처럼 기능보다 형식이 먼저 보이는 이름을 더 쉬운 명칭으로 통일한다.
- 계산기별 ‘계산 기준’ 문장을 모바일에서 두세 문장 안에 읽히도록 한 번 더 압축한다.
