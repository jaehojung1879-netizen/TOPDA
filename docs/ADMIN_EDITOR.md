# TOPDA 관리자 레이아웃 편집기

정적 HTML 사이트에서 글씨 크기, 카드와 표 셀 크기, 여백, 정렬을 브라우저에서 바로 미세 조정하기 위한 편집 도구입니다.

## 시작하기

1. 사이트의 아무 페이지에서 오른쪽 아래 `✦` 버튼을 누르거나 `Ctrl + Shift + E`를 입력합니다.
2. 초기 편집 코드 `TOPDA-EDIT`를 입력합니다.
3. 수정할 텍스트, 카드, 표 셀 등의 요소를 클릭합니다.
4. 오른쪽 패널에서 글씨 크기, 줄 간격, 자간, 정렬, 너비, 최소 높이, 여백, 모서리 값을 조절합니다.
5. 상단의 `저장`을 누릅니다. 변경사항은 브라우저 `localStorage`에 페이지별로 저장되며, 해당 브라우저에서는 다음 방문부터 자동 적용됩니다.

`?edit=1` 쿼리 문자열을 페이지 URL 뒤에 붙이면 코드 입력 창을 바로 열 수 있습니다.

## 주요 기능

- 페이지 요소 클릭 선택과 hover 가이드
- PPT와 유사한 슬라이더 및 숫자 직접 입력
- 실행 취소와 다시 실행
- 선택 요소 초기화
- 페이지별 스타일 저장 및 방문 시 자동 복원
- JSON 내보내기와 불러오기를 통한 다른 브라우저 전달
- 모바일 편집 패널 및 인쇄 시 자동 숨김

## 편집 코드 변경

정적 사이트에서는 브라우저 개발자 도구로 코드를 확인할 수 있으므로 현재 코드는 보안 인증이 아니라 실수 방지용 진입 장벽입니다. 개발자 콘솔에서 아래 명령을 실행하면 현재 브라우저에서 사용할 코드를 바꿀 수 있습니다.

```js
localStorage.setItem('topda-editor-passcode', '새로운-편집-코드')
```

사이트를 서버 기반으로 전환할 때는 로그인 세션을 서버에서 검증하고, `editor.js` 로드 여부와 저장 API 접근 권한을 관리자 세션에 따라 제한해야 합니다. 서버 저장을 붙이기 전까지 변경사항은 JSON으로 내보내어 전달하고, 검토가 끝난 확정 스타일만 코드에 반영하는 방식을 권장합니다.
